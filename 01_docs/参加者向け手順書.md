# Research LLM Agent 参加者向け手順書

卒業研究のための実験用コーディングエージェントです。VS Code のサイドバーで AI に依頼し、ファイルの編集やコマンドの実行を手伝ってもらえます。

## 1. 用意するもの

- VS Code（1.90 以降）。未インストールなら https://code.visualstudio.com/ から入れてください
- 鈴木から受け取った **招待コード**（例 `ABCD-EF23`）

## 2. インストール

配布された ZIP を**必ず展開してから**、展開したフォルダの中の次のファイルをダブルクリックします（ZIP を開いただけの状態で実行するとエラーになります）。

| OS | 展開のしかた | 実行するファイル |
|---|---|---|
| Windows | ZIP を右クリック →「すべて展開」 | `install.cmd` |
| macOS | ZIP をダブルクリック | `install.command` |

- Windows で「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を押してください
- macOS で「開発元を確認できない」「Apple は検証できませんでした」と表示されたら、いったん「完了」（または「キャンセル」）を押し、次のどちらかで開いてください
  - `install.command` を右クリック →「開く」→「開く」
  - 上の方法で開けない場合（macOS 15 以降）：「システム設定」→「プライバシーとセキュリティ」を開き、下の方にある「このまま開く」を押す

うまくいかない場合は、VS Code を開き、`research-llm-agent.vsix` を拡張機能ビュー（左端の四角いアイコン）にドラッグ＆ドロップしてください。

## 3. 利用開始

1. VS Code でプロジェクトのフォルダを開きます（「ファイル」→「フォルダーを開く」）
2. 左端の「Research LLM」アイコンをクリックします
3. 招待コードを入力します
4. 研究への同意画面で内容を確認し、①〜③に同意します（すべての同意が利用の条件です）

## 4. 使い方

- 下の入力欄に依頼を書き、Ctrl+Enter（macOS は Cmd+Enter）で送信します
- 画像（エラー画面のスクリーンショットなど）も一緒に送れます。入力欄に貼り付ける（Ctrl+V）か、「画像を添付」から選んでください（1回に4枚まで）。添付した画像も研究用ログとして収集されます
- ファイルの変更・コマンドの実行の前に確認が表示されます
  - **承認**：実行します
  - **拒否**：実行せず、依頼を終了します
  - **修正を指示して拒否**：実行せず、修正してほしい内容を AI に伝えます
- ファイル変更の内容はエディタの差分画面で確認できます
- 「中止」で生成・実行を止められます。「新しい会話」で会話をリセットできます
- Unity や Processing のプロジェクトも扱えます。エディタ上の操作（再生など）は AI からはできないので、Unity／Processing 側で行ってください

## 5. ログ収集の一時停止

私用の作業をするときや、他の人の情報を含むファイルを扱うときは、ログ収集を一時停止してください。

**一時停止中はエージェントを使えません。** 一時停止中の作業は記録されないので、エージェントを使わずに作業してください。

1. 画面上部の「収集を一時停止」、または画面右下のステータスバー「研究: 収集中」をクリックします
2. ステータスバーが「研究: 収集一時停止中」に変わり、入力欄が使えなくなります。実行中の依頼があった場合は中止されます
3. エージェントを再び使うときは、画面上部の「収集を再開」（またはステータスバー）をクリックします。ログ収集が再開され、入力欄が使えるようになります

## 6. 同意の撤回

画面上部の「同意」から、いつでも撤回できます。撤回すると利用は停止されます（再開には鈴木への連絡が必要です）。撤回時に、これまでのデータの削除を依頼することもできます。

## 7. 注意

- 個人情報・パスワード・API キーなどの秘密情報を含むファイルや画像は扱わないでください（`.env` などはエージェントが読めないようにしています）
- 入力内容・添付した画像・AI が読んだファイルは Google の Gemini API に送られ、無料枠の規約により Google のサービス改善に使われることがあります
- 1日の利用回数には上限があります。画面上部の「本日 ○/50回（17:00にリセット）」で、今日使った回数と、回数が 0 に戻る時刻を確認できます。上限に達したら、表示されている時刻（日本時間の夕方）まで待ってください
- 回数が 0 に戻るのは表示されている時刻だけです。ログ収集の一時停止・再開をしても回数は変わりません
- 困ったときは鈴木に連絡してください
